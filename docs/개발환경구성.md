# 개발환경 구성 — livertree

## 1. 시스템 요구사항

| 도구 | 버전 |
|---|---|
| Python | 3.12 (CPython) |
| Node.js | 22.x LTS |
| npm | 10.x (Node 22 동봉) |
| SQLite | 3.45+ (FTS5 trigram 토크나이저 필요) |
| Docker | 24.x + compose v2 (배포 시) |
| Playwright | 1.48 (자동 설치) |

## 2. 로컬 셋업

### 2.1 저장소 클론
```bash
git clone <repo> livertree
cd livertree
```

### 2.2 Python 환경
```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
python -m playwright install chromium
```

`requirements.txt` 패키지 해설:

| 패키지 | 용도 |
|---|---|
| `requests` | HTTP 요청 (대부분의 크롤러) |
| `cloudscraper` | Cloudflare 우회 다운로드 |
| `beautifulsoup4` | HTML 파싱 |
| `playwright` | JS 렌더링 사이트용 (mohw 등) |
| `openai` | OpenAI 요약 / Auto-Add |
| `google-genai` | Gemini 대체 LLM |
| `python-dotenv` | `.env` 로딩 |
| `openpyxl` | qa 스크립트 Excel 출력 |

선택 패키지 (PDF/HWP 텍스트 추출):
```bash
pip install pdfplumber PyPDF2 olefile
```
없으면 converter 가 자동으로 fallback.

### 2.3 Node 환경 (finolaw)
```bash
cd finolaw
npm ci
```

`package.json` 핵심 deps:

| 패키지 | 용도 |
|---|---|
| `next 16.2` | App Router + Route Handlers |
| `react 19.2`, `react-dom` | UI |
| `better-sqlite3 12.9` | 동기 SQLite (read-only) |
| `tailwindcss 4` (devDep) | 스타일링 |
| `typescript 5` (devDep) | 타입 검사 |
| `eslint 9`, `eslint-config-next` | 정적 분석 |

### 2.4 환경 변수
```bash
cp .env.example .env
cp crawler/.env.example crawler/.env
# 두 파일에 키 채우기:
#   OPENAI_API_KEY (필수)
#   GEMINI_API_KEY (선택)
#   LLM_PROVIDER (gpt|gemini, 기본 gpt)
#   ADMIN_BASIC_AUTH_USER / ADMIN_BASIC_AUTH_PASS (운영 시)
```

### 2.5 DB 초기화
```bash
python -m scripts.migrate_livertree            # documents 테이블
python -m scripts.migrate_documents_fts        # FTS5 가상 테이블
```

### 2.6 첫 실행
```bash
# 백엔드 첫 수집
python -m crawler.main crawl ntrs --limit 5
python -m crawler.main download ntrs
python -m crawler.main convert ntrs
python -m crawler.main summarize ntrs

# 프론트엔드 dev 서버
cd finolaw
npm run dev      # http://localhost:3001
```

## 3. 개발 워크플로

### 3.1 단위 테스트
```bash
python -m unittest tests.test_storage -v
```
26 테스트 / 0 실패 기대.

### 3.2 정적 검사
```bash
cd finolaw
npx tsc --noEmit
npm run lint
```

### 3.3 코드 리뷰
프로젝트는 Codex 자동 리뷰 사이클을 사용한다:
```bash
/codex:review              # 변경 사항 review
/codex:adversarial-review  # 추가 검증
```

### 3.4 디렉터리 구조
```
livertree/
├── crawler/                  # Python 크롤러 패키지
│   ├── main.py               # CLI entry point
│   ├── base_crawler.py       # 공통 베이스
│   ├── db.py                 # SQLite 스키마 + 헬퍼
│   ├── storage.py            # 12자리 path 유틸
│   ├── livertree_adapter.py  # 레거시 paper_dict → document_dict
│   ├── summarizer.py         # OpenAI/Gemini 요약
│   ├── analyzer.py           # auto-add 사이트 분석
│   ├── llm_providers.py      # LLM 추상화
│   ├── converter.py          # PDF/HWP/HWPX 추출
│   ├── agent_tools.py        # auto-add 보조
│   ├── codex_runner.py       # auto-add-codex 보조
│   ├── smart_finder.py       # smart-find 엔진
│   └── sites/                # 사이트별 크롤러
├── finolaw/                  # Next.js 16 admin UI
│   ├── src/app/              # App Router 페이지 + API
│   └── src/lib/              # db.ts, cache.ts 등
├── scripts/                  # 마이그레이션, qa, cron
├── tests/                    # unittest
├── docker/                   # supervisord.conf
├── docs/                     # 문서
├── data/                     # papers.db + 12자리 파일 (gitignored)
├── Dockerfile
├── docker-compose.yml
├── requirements.txt
└── README.md
```

## 5. 트러블슈팅

| 증상 | 조치 |
|---|---|
| `ModuleNotFoundError: bs4` | `pip install beautifulsoup4` |
| `playwright._impl._errors.Error: Executable doesn't exist` | `python -m playwright install chromium` |
| `tsc not found` | `cd finolaw && npm ci` |
| FTS5 검색 결과 없음 | `documents_fts` 미생성. `migrate_documents_fts` 실행 |
| Next.js 빌드 실패 | Node 22 사용 확인 (`node -v`) |

## 6. CI / 자동화 (참고)

현재 별도 CI 파이프라인은 없다. PR 단위로 다음을 권장:

1. `python -m unittest tests.test_storage`
2. `cd finolaw && npx tsc --noEmit && npm run lint`
3. `/codex:review`
4. 머지 후 운영 호스트에서 `git pull && docker compose build && docker compose up -d`
