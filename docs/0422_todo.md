### 전체 DOC_ID 인덱스 구축

#### ☐ 12. 사이트 전체 인덱스 테이블 생성
현재 "사이트에 총 뭐가 있는지" 전체 목록이 없음.
리스트 API만 빠르게 스캔하여 전체 DOC_ID 인덱스를 별도 테이블에 저장.

**테이블 스키마:**
```sql
CREATE TABLE doc_index (
    doc_id      TEXT NOT NULL,
    site_id     TEXT NOT NULL,
    doc_number  TEXT,
    title       TEXT,
    doc_type    TEXT,
    published_date TEXT,
    scanned_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(site_id, doc_id)
);
```

**용도:**
- `doc_index` vs `papers` 비교 → 미수집 건 정확히 파악
- 기존 문서 수정 감지 (title/date 변경 추적)
- xlsx 비교 도구의 기준 데이터로 활용

**구현 위치:** `crawler/sites/nts_taxlaw.py` — `scan_index()` 메서드
**CLI:** `--scan-index` 옵션
**cron:** 주 1회 인덱스 갱신 (일요일 새벽 등)
