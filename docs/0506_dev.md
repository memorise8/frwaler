## 1. 56K 제품 DB 통합 (404 → 자동 PDF 다운로드)

### 문제
- 60개 heritage DB에는 없지만 56K 크롤러 DB에는 있는 부품(`2N6766` 등)이 `404 not found in heritage DB`로 막힘.
- 사용자 입장에서 "왜 자동완성에 뜨는데 분석은 안 되지?" 혼란.

### 해결
**신규 `pro_server/services/products_lookup.py`**
- `find_product(db_path, mpn, device_type)`: external_id / name prefix 대소문자 무시 매칭. `datasheet_url`이 있는 행 우선.
- `fetch_datasheet_bytes(url, max_bytes=20MB, timeout=25s)`: httpx로 PDF 다운로드 + 사이즈/타임아웃 가드.

**`pro_server/routers/screening.py` (BJT/MOSFET 양쪽)**
- 3단계 chain:
  1. heritage DB 조회
  2. miss → products DB fallback
  3. `datasheet_url` 있으면 자동 fetch → 파서로 추출
- 각 단계 실패 시 구조화된 에러 detail 반환 (아래 §3).

## 2. Gemini 2.5-flash thinking 모드 토큰 소진 버그

### 증상
Vishay PDF (Si4485DY 등) 추출 시 `"No LLM provider configured"`. 실제 원인은 thinking mode가 `max_output_tokens=1024`를 조용히 다 써서 JSON 응답이 잘려 파싱 실패 → fallback 실패.

### 해결 (`pro_server/services/datasheet_parser.py`)
- `max_output_tokens` 기본값 `1024 → 8192` (`_call_gemini`, `_call_openai`, MOSFET 전용 inline call 모두).
- Gemini config에 `thinking_config: {thinking_budget: 0}` 추가하여 thinking 자체를 비활성화 (BJT + MOSFET 양쪽).
- 검증: Si4485DY 추출 성공, confidence 0.91, 11개 MOSFET 파라미터 모두 채워짐.

## 3. 친절한 에러 UX (raw JSON → 안내 카드)

### 사용자 피드백
> `{"detail":"'2N6756'이(가) 부품 DB에 있지만 데이터시트 링크가 없습니다..."}`
> 이렇게 뭔가 시스템이 잘못된거 처럼 나오지 않게 UI를 바꾸는게 좋을거 같은데?

### BE — 구조화된 에러
**`pro_server/routers/screening.py`**
- `HTTPException.detail`을 dict로 변경. 3가지 `error_code`:
  - `needs_upload`: products DB에 있으나 datasheet_url 없음
  - `not_found`: 두 DB 모두에 없음
  - `fetch_failed`: datasheet_url 있으나 다운로드 실패
- payload: `{ error_code, mpn, message, product_url?, brand?, datasheet_url? }`

### FE — 타입/에러 클래스
**`web/src/lib/api.ts`**
- `ScreeningGuidance` 타입, `ScreeningError extends Error`, `parseScreeningError(res)` 추가.
- BJT/MOSFET 4개 함수의 `throw new Error(await res.text())` → `throw await parseScreeningError(res)`.

### FE — 안내 카드
**신규 `web/src/components/screening/ScreeningGuidanceCard.tsx`**
- `error_code`별 팔레트: cyan(needs_upload) / purple(not_found) / amber(fetch_failed).
- 제목 가변: "데이터시트가 필요합니다" / "아직 등록되지 않은 부품" / "자동 다운로드 실패".
- 번호 매긴 step list: 외부 링크(target=_blank, ↗ 마커) + "업로드 영역으로 스크롤" 버튼.

### FE — 페이지 통합
**`web/src/app/screening/page.tsx`**
- `mpnGuidance` state 추가, `pdfPanelRef`, `scrollToUpload()` (mpn/manufacturer 자동 채우기 포함).
- `handleMpnSubmit` catch: `ScreeningError` + `guidance` 있으면 카드, 아니면 기존 빨간 에러 박스.
