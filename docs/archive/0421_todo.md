## 우선 구현 TODO

### ☐ Gap fill 전용 모드 (`--gap-fill`)
현재 gap fill은 전체 재크롤링(upsert) 방식 → 13만건 전체 순회에 ~61시간.
미수집 건만 빠르게 채우는 전용 모드 필요.

**로직:**
1. 리스트 API만 빠르게 순회 (상세 API 호출 없이 DOC_ID만 수집)
2. 수집한 DOC_ID 목록과 DB 비교 → 미수집 DOC_ID 필터
3. 미수집 건만 상세 API 호출 + 저장

**효과:** 리스트 순회는 빠르고(delay만), 상세 fetch는 ~15,000건만 → **2~3시간**이면 완료

**구현 위치:**
- `crawler/sites/nts_taxlaw.py` — `gap_fill()` 메서드 추가 or `crawl(mode='gap-fill')`
- `crawler/main.py` — `--gap-fill` CLI 옵션

### ☐ xlsx 비교 도구 (gap 분석)
사람이 수동 정리한 xlsx 목록과 DB를 대조하여 빠진 건 감지.

**흐름:**
```
[input.xlsx]                    [papers.db]
 문서번호 | 제목 | 날짜 ...       문서번호 | 제목 | 날짜 ...
        ↓                           ↓
     pandas로 읽기               sqlite3로 읽기
                 ↓
           문서번호 기준 매칭
                 ↓
   A. xlsx에만 있음 → 미수집 (자동 재수집 대상)
   B. DB에만 있음 → 신규 발견 (xlsx에 없는 건)
   C. 양쪽 다 있음 → OK
                 ↓
         gap_report.md 출력
```

**구현 위치:** `scripts/compare_xlsx.py`
**cron 연동:** 주기적으로 비교 → 미수집 건 자동 보충 가능
