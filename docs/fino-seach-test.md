# Fino Search 가능성 테스트

## 목적

`input.xlsx` (20,352건, 고유 17,171건)의 문서번호를 `taxlaw.nts.go.kr` API로 검색해 메타데이터(제목/유형/분류/생산일자)를 복원할 수 있는지 가능성 확인.

## 테스트 환경

- API: `POST https://taxlaw.nts.go.kr/action.do` (actionId=`ASIPDI002PR01`)
- 검색 필드: `icldVcbCtl` (키워드)
- 대상 컬렉션
  - 판례: `precedent,precedent_gr` (DCM 코드 `001_05`~`001_10`)
  - 해석례: `question,question_gr` (DCM 코드 `001_01`~`001_04`)

## 추출 필드 매핑 (응답 → 결과)

| 결과 필드 | 응답 키 | 비고 |
|-----------|---------|------|
| 검색어 | (입력값) | `input.xlsx` 원본 |
| 제목 | `TTL` | |
| 유형 | `NTST_DCM_CL_NM` | 심사/심판/판례/질의 등 |

| 생산일자 | `DCM_RGT_DTM` 앞 8자리 | `YYYYMMDD` |

## 분석

### ✅ 4건 모두 매치 가능

- `감심-YYYY-NNNN` (감사원 심사결정) → 판례 컬렉션
- `조심-YYYY-지역-NNNN` (조세심판원) → 판례 컬렉션
- `YYYY가합NNNNNN` (민사 판결) → 판례 컬렉션
- `법인46012-NNNN` (국세청 예규) → 해석례 컬렉션

### ⚠️ 주의: 정확 매치 필터링 필요

1차 테스트에서 `법인46012-3406`이 "미매치"로 잘못 판단된 원인:

- `icldVcbCtl`은 **키워드 전문 검색**이라 본문/제목에 해당 번호를 언급하는 최신 문서들이 먼저 반환됨
- 기본 `viewCount=10`으로는 정렬(DCM_RGT_DTM/DESC) 상 최근 문서 10건에 실제 대상 문서(1998년)가 밀려남
- 결과 리스트를 `NTST_DCM_DSCM_CNTN`(문서번호) 정확 매치로 필터링해야 원본을 찾을 수 있음

**검증:** 날짜 범위(`bltnStrtDt=19980101`, `bltnEndDt=20020101`) 필터 추가 시 첫 페이지에서 바로 매치됨.

## 결론

**가능성: 충분히 가능** — 4/4 매치. 생산일자 없어도 전수 검색 가능.

### 구현 전략

1. **1차 조회**: `icldVcbCtl=[검색어]`로 viewCount=50~100 조회
2. **정확 매치 필터**: 응답 `body[].dcm.NTST_DCM_DSCM_CNTN`에서 `<!HS>`/`<!HE>` 태그 제거 후 검색어와 일치하는 항목 추출
3. **Fallback**: 1차에서 못 찾으면 페이지네이션으로 추가 스캔 or 날짜 범위 좁혀 재조회
4. **최종 미매치**: 헌법재판소(`2000-헌마-8-`), 감사원 자체(`bai.go.kr`) 등 비-세무 DB는 별도 소스 필요
