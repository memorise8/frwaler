# 상세 기능정의서 — livertree

## 1. 데이터 모델

### `documents` (livertree 핵심 테이블)

| 컬럼 | 타입 | 설명 | 제약 |
|---|---|---|---|
| `id` | INTEGER | 12자리 글로벌 시퀀스 | PRIMARY KEY AUTOINCREMENT |
| `crawled_at` | TIMESTAMP | DB INSERT 시각 | DEFAULT CURRENT_TIMESTAMP |
| `site_id` | TEXT | 사이트 ID | NOT NULL, FK→sites.id |
| `external_id` | TEXT | 사이트 내 글번호 | UNIQUE(site_id, external_id) |
| `meta_url` | TEXT | 게시글 페이지 URL | |
| `title` | TEXT | 제목 | |
| `published_date` | TEXT | 작성일/출판일 | |
| `posted_date` | TEXT | list 게시일 | |
| `authors` | TEXT | 저자 (`; ` 구분) | |
| `publisher` | TEXT | 출판사/기관 (`; ` 구분) | |
| `journal` | TEXT | 출판된 저널 | |
| `pdf_url` | TEXT | 첨부파일 URL | |
| `keywords` | TEXT | 키워드 (`, ` 구분) | |
| `abstract` | TEXT | 초록/본문 | |
| `original_filename` | TEXT | 원본 PDF 파일명 | |
| `pdf_path` | TEXT | 다운로드 경로 (data/AAAA/BBBB/N.ext) | |
| `txt_path` | TEXT | 변환 결과 경로 (.txt) | |
| `download_status` | TEXT | pending/downloaded/failed | |
| `summary` | TEXT | LLM 요약 | |
| `metadata` | TEXT | 사이트별 raw JSON (NTS documentTypeName 등) | |

### `sites`

| 컬럼 | 설명 |
|---|---|
| `id` | 사이트 코드 (`ntrs`, `mohw` 등) |
| `name` | 표시명 |
| `base_url` | 기본 URL |
| `last_crawled` | 마지막 크롤링 시각 |

### `documents_fts` (가상 테이블)

`title, abstract, summary, metadata` 4 컬럼 trigram FTS5. INSERT/UPDATE/
DELETE 트리거가 자동으로 동기화한다.

## 2. CLI 기능 (`python -m crawler.main <subcommand>`)

| 서브커맨드 | 기능 | 주요 인자 |
|---|---|---|
| `crawl <site>` | 사이트 크롤링 → documents INSERT | `--limit`, `--incremental` |
| `download [site]` | pdf_url 다운로드 (magic-byte sniffer) | `--limit`, `--retry` |
| `convert [site]` | 다운로드된 파일 → .txt 추출 | `--limit` |
| `summarize [site]` | 미요약 문서 일괄 LLM 요약 | `--limit`, `--provider`, `--doc-id` |
| `stats` | 사이트별 카운트 + 다운로드 진행률 | — |
| `list-sites` | 등록된 사이트 목록 | — |
| `scan-index` | doc_index 갭 분석 | `<site>`, `--limit` |
| `test-config <site>` | generic JSON config 검증 | `--limit` |
| `smart-find <url>` | URL 분석 + 문서 발견 (LLM) | `--save-db`, `--max-pages` |
| `auto-add <url>` | GPT 에이전트로 신규 사이트 config 생성 | `--browser`, `--dry-run` |
| `auto-add-codex <url>` | Codex CLI 기반 사이트 config 생성 | `--timeout-seconds` |

## 3. 관리자 UI 기능 (Next.js Server Components)

| 라우트 | 기능 | 주요 컴포넌트 |
|---|---|---|
| `/` | 전체 통계 + 최근 문서 + 사이트 요약 | Stat 카드 4종, QuickLink 4종, 표 2종 |
| `/search` | LIKE 또는 FTS5 검색 + 다중 필터 + 페이지네이션 | 폼, 결과 리스트, 페이지 링크 |
| `/search/[id]` | 단건 상세 (제목, badge, 본문, metadata) | 페이퍼 헤더, 메타 표시 |
| `/admin/status` | 사이트별 수집/다운로드/변환/요약 진행률 | Stat 5종, ProgressBar 표 |
| `/admin/summary` | 요약 완료/미완료 필터링 + 재요약 | 폼, 리스트, RegenerateButton (client) |
| `/smart-find` | URL → 문서 자동 발견 (스트리밍) | 클라이언트 (NDJSON 처리) |
| `/auto-add` | URL → 자동 크롤러 config 생성 (스트리밍) | 클라이언트 |
| `/crawler` | 크롤 작업 큐 + 로그 스트리밍 | 클라이언트 (5초 폴링) |

| Route | Method | 입력 | 출력 |
|---|---|---|---|

## 5. 라이브러리 함수 (`finolaw/src/lib/db.ts`)

| 함수 | 반환 타입 | 용도 |
|---|---|---|
| `getDbStats()` | `DbStats` | 메인 대시보드 4 카운트 |
| `getCollectionProgress()` | `SiteProgress[]` | /admin/status 사이트별 진행률 |
| `getCollectionTotals()` | `CollectionTotals` | /admin/status 글로벌 롤업 |
| `getDocumentsBySummaryStatus()` | `SummaryListResult` | /admin/summary 필터 + 페이지 |
| `getRecentPapers(siteId?, limit)` | `Paper[]` | 대시보드 + markdown export |
| `searchPapers(filters)` | `SearchResult` | /search FTS5 + 필터 |
| `getPaper(id)` | `Paper \| null` | 상세 페이지 |
| `getDocTypeCounts()` | `DocTypeCount[]` | 대시보드 NTS 분류 |
| `getCategories()` | `string[]` | 카테고리 dropdown |
| `getAllSitesSummary()` | `SiteCount[]` | 등록 사이트 표 |
| `getDocumentById(id)` | `LivertreeDocument \| null` | 단건 조회 (livertree 형식) |
| `parseMetadata(raw)` | `PaperMetadata` | metadata JSON 안전 파싱 |
| `splitAuthors / splitKeywords / splitPublishers` | `string[]` | 구분자 문자열 split |
