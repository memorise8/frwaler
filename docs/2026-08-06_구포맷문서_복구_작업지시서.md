## 3. 작업 순서

### ① 작업목록 CSV를 엑셀로 엽니다

`순위` 열을 보세요.

- **1순위(필수)** — 90개. **이것만 해주셔도 됩니다.** 이 파일들은 다른 대체 자료가 전혀 없어서, 안 하면 그 자료는 통째로 못 씁니다.
- **2순위(여유되면)** — 69개. 같은 자료의 다른 형식 파일(PDF 등)이 이미 확보돼 있어서, 안 해도 큰 손해는 없습니다. **1순위를 다 끝낸 뒤에** 시작하세요.

### ② 파일을 한글 프로그램으로 엽니다

CSV의 `원본파일명`과 `원본파일_위치`를 보고 해당 파일을 찾아 여세요.

### ③ 다른 이름으로 저장 → **PDF**

- `파일` → `다른 이름으로 저장하기` → 형식 **PDF** 선택
- 저장 위치는 **`복구완료` 폴더**

> 💡 PDF가 어려우면 `한글 문서(*.hwp)` 최신 형식으로 저장하셔도 됩니다. 둘 다 처리 가능합니다.

### ④ 파일 이름은 **절대 바꾸지 마세요** ← 가장 중요

```
원본:  001_14137_Forum11회.hwp
저장:  001_14137_Forum11회.pdf      ← 확장자만 바뀌고 이름은 그대로
```

파일 이름 앞의 두 숫자가 식별 번호입니다.

| `001` | 작업번호 — CSV의 `작업번호` 열과 같습니다 |
|---|---|
| `14137` | **자료번호** — 어느 게시글의 자료인지 알아보는 번호 |

이게 바뀌면 시스템이 원래 게시글과 연결하지 못합니다.
- ❌ `001_14137_Forum11회_수정.pdf`
- ❌ `Forum11회.pdf`
- ❌ `제11회 금융구조조정과 회계발전.pdf`

> 파일명이 같아 보이는 것이 몇 개 있습니다(예: `091_14104_1.주요논점정리.hwp`, `092_14104_2.재무보고서.hwp`).
> 한 게시글에 여러 자료가 붙어 있어서 그렇습니다. **앞의 작업번호가 다르면 서로 다른 파일**이니 각각 작업해 주세요.

### ⑤ CSV의 `완료` 열에 `O` 표시

한 줄 끝낼 때마다 표시해 주세요. 중간에 멈췄다가 다시 시작하기 편합니다.

## 4. 이런 경우엔 이렇게 해주세요

| 상황 | 조치 |
|---|---|
| **파일이 아예 안 열림** (오류·깨짐) | `파일이_안열림` 열에 `O`, 넘어가세요. 억지로 복구하지 마세요 |
| **암호가 걸려 있음** | 위와 동일. `메모` 열에 "암호" |
| **열었는데 내용이 텅 비어 있음** | `메모` 열에 "빈문서", 저장하지 말고 넘어가세요 |
| **글자는 없고 그림·도표만 있음** | 그래도 **저장해 주세요.** 나중에 그림에서 글자를 뽑는 작업을 따로 합니다. `메모` 열에 "그림위주" |
| **글자가 다 깨져서 보임(□□□)** | `메모` 열에 "깨짐". 저장은 해주세요 — 일부라도 살릴 수 있는지 확인합니다 |
| **같은 내용이 반복되는 것 같음** | 신경 쓰지 마세요. 중복은 시스템이 자동으로 걸러냅니다 |

원본 게시글을 직접 보고 싶으시면 CSV의 `게시글주소`를 브라우저에 붙여넣으면 됩니다.
