반영된 주요 변경

  • DOAJ의 3건 실행 반복 정체를 수정했습니다. 기존 2만 건·신규 200건 조건에서 3건씩 18회 이후 잔여를 수집해 총 신규 200건 저장을 확인했습니다.
  • HAL 6개는 10건 페이지 중 3건 처리 후 위치 3에서 재개합니다. 실패한 페이지를 건너뛰지 않으며, 옛 커서는 처음부터 중복 제거 재탐색합니다.
  • 8개 검색 키의 전달 경로와 오류 분류를 보강했습니다. 키 값은 FE 응답·문서·번들에 포함하지 않습니다.
  • 기존 문서의 PDF·텍스트만 처리하는 API·화면과 파일 워커를 추가했습니다. PDF는 이전에도 일부 경로에서 수집됐으며, 이번 변경은 FE에서 실행·복구·상태 확인하는 경로를 보완한 것입니다.
  • 건강 점검 화면, 기능·제한 표시, 시험 실행 확인을 연결했습니다. FE 빌드는 Google Fonts 접속 없이 수행됩니다.

검증 결과의 의미

  • Python 전체 361개 발견: 181개 통과, 180개 PostgreSQL 의존 테스트 미실행. FE 304개 통과, 타입 검사·린트·프로덕션 빌드 통과.
  • 기본·blob·health Compose를 더미 설정으로 구문 검증했습니다. 컨테이너를 설치하거나 기동한 검증은 아닙니다.
  • 실사이트 요청·키 유효성·브라우저 화면·새 DB 설치·기존 DB 업그레이드는 현재 환경의 네트워크·Docker·소켓 제한으로 수행하지 못했습니다.
  • 코드 분석 및 SQLite 격리 테스트는 PostgreSQL 운영 통합 검증을 대체하지 않습니다. 원본 목록 변경, 동률 날짜, 지연 등록의 누락 방지 검증도 남아 있습니다.

  1. 격리된 검증 환경에서 DB와 PDF 저장소 백업을 확보하고 기존 예약·실행 작업을 정리합니다.
