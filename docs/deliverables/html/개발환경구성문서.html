1. 개요

본 서비스는 웹페이지·문서를 수집하고 텍스트로 변환·분석하여 요약을 생성하는 시스템으로, 하나의 저장소(crawler-poc) 안에 세 개의 구성요소와 하나의 데이터 계층으로 이루어진다. 세 구성요소는 공통의 data/ · libertree/ 저장소를 형제 경로로 참조한다.

데이터SQLite (WAL) + 파일 블랍-libertree.db 및 libertree/ 블랍 트리
열람앱(libertree-app)은 관리자앱(finolaw)과 독립된 격리 런타임이다. 크롤러 스케줄러·Supervisor가 없으며, DB와 블랍을 읽기 전용으로만 마운트하여 카탈로그 열람 전용으로 동작한다.

4. 환경변수

루트 .env(관리자앱 인증)와 crawler/.env(크롤러·LLM)로 분리되며, 열람앱은 컨테이너 배포 시 LIBERTREE_* 계약값을 명시적으로 주입받는다.

변수명파일/대상필수용도
ADMIN_USER루트 .env / 전 앱조건부HTTP Basic 인증 사용자명. 열람앱 배포 시 필수
ADMIN_PASSWORD루트 .env / 전 앱조건부Basic 인증 비밀번호. 둘 다 비우면 인증 비활성(로컬 개발 전용)

GEMINI_API_KEY / GOOGLE_API_KEYcrawler/.env선택Smart Finder AI 폴백 및 요약 Gemini 경로

SUMMARIZER_MODELcrawler/ (환경변수)선택요약 모델. 기본 gpt-5.4-mini

LIBERTREE_BLOB_ROOT열람앱 (배포) / 크롤러필수블랍 저장 루트. 크롤러 기본은 저장소 루트 libertree/
LIBERTREE_DATA_ROOT열람앱조건부데이터 디렉터리 루트(WAL/SHM 사이드카 포함 마운트용)
사이트별 공개 검색 키
(*_KEY / *_PUBLIC_KEY)		crawler/.env선택일부 사이트 공개 읽기전용 검색 API 키 (예: CANCER_FR_CATALOGUE_DES_PUBLIC_KEY, INRAE_FR_ACTUALITES_KEY 등)
컨테이너 배포용 호스트측 변수(열람앱 docker-compose.yml): LIBERTREE_HOST_APP_DATA_ROOT(=libertree-app/data/ 절대경로), LIBERTREE_HOST_BLOB_ROOT(=저장소 루트 libertree/), LIBERTREE_HOST_PORT(선택, 기본 3101). 기동 게이트는 쓰기가능/누락 마운트, 변경된 데이터 경로, 크롤러·외부 AI 키 환경변수를 거부한다.
참고: 위 OPENAI_API_KEY/SUMMARIZER_MODEL은 crawler/summarizer.py의 온디맨드 요약 경로용이다. 실제 프로덕션 대량 요약은 로컬 Ollama 배치(scripts/bulk_summarize_gemma.py, 포트 11436, gemma4:26b·qwen3:8b)로 수행됐다 — 5.4 참조.

5. 로컬 실행 절차

5.1 크롤러

# 저장소 루트에서 (Python 3.12 venv)
source .venv/bin/activate           # 또는 직접 .venv/bin/python 사용

# 등록된 사이트/통계 확인
python -m crawler.main list-sites
python -m crawler.main stats

# 수집 실행 (예)
python -m crawler.main crawl <site>

# 지원 서브커맨드: crawl · list-sites · stats · test-config · download · convert

5.2 관리자앱 finolaw (포트 3001)

cd finolaw
npm install
npm run dev            # http://localhost:3001

# 프로덕션
npm run build
npm run start          # 포트 3001
finolaw는 형제 경로에 의존한다: ../crawler/, ../.venv/bin/python, 대시보드/검색용 DB, ../.cache/ 로그, ../crawler/.env. DB가 없으면 UI는 기동되나 대시보드/검색 데이터가 비어 있다.

5.3 열람앱 libertree-app (dev 포트 3000)

cd libertree-app
npm install
npm run dev            # http://localhost:3000 (기본 포트)

# 데이터 계약 검증 스크립트
npm run verify:data-path
npm run print:data-contract
npm run verify:app-surface

5.4 요약 백엔드

요약 경로는 두 가지가 존재한다:

  • 대량 배치(프로덕션 실사용) — scripts/bulk_summarize_gemma.py가 로컬 Ollama(127.0.0.1:11436)를 호출한다. 실제 저장된 요약 66,248건은 전부 이 경로로 생성됐다(DB summary_model 실측: gemma4:26b 55% + qwen3:8b 45%).
  • 온디맨드 재요약 — crawler/summarizer.py(관리자 화면의 재요약·crawler.main summarize)는 OpenAI(SUMMARIZER_MODEL 기본 gpt-5.4-mini, 폴백 gpt-4o-mini)·Gemini(gemini-2.5-flash) 경로를 사용한다. 이 경로는 코드에 존재하나 프로덕션 대량 요약에는 미사용이다.
계약(REQ-2026-001)은 OpenAI API를 명시했으나, 비용·온프레미스 이유로 실제 대량 요약은 로컬 Ollama 모델로 구현했다. OpenAI/Gemini 경로는 온디맨드 보조 수단으로 코드에 보존돼 있다.

6. 컨테이너 실행

6.1 통합 배포 (루트 docker-compose.yml)

단일 app 컨테이너가 Next.js(3001, supervisord 구동)와 Python3 + Playwright + Codex CLI(크롤 시 온디맨드 실행)를 함께 운영한다.

cp .env.example .env
cp crawler/.env.example crawler/.env
# 두 파일 편집 후:
docker compose up -d
항목값
서비스 / 이미지app / crawler-poc:mvp (컨테이너 crawler-poc)
포트3001:3001
env_file.env, crawler/.env
볼륨./data, ./libertree(읽기전용), ./.cache, ./crawler/sites/custom, ./crawler/sites/configs
헬스체크HEAD / 응답 200 또는 401 (인증 뒤에서도 5xx 아님) / 30s 간격

6.2 열람앱 격리 배포 (libertree-app/docker-compose.yml)

기존 3001 서비스와 무관한 카탈로그 전용 컨테이너로, 루프백에만 게시하며 기본 호스트 포트는 3101이다.

cd libertree-app
docker compose -f docker-compose.yml build
docker compose -f docker-compose.yml up -d
curl --fail --user "$ADMIN_USER:$ADMIN_PASSWORD" http://127.0.0.1:3101/api/health
docker compose -f docker-compose.yml down
항목값
서비스catalogue (compose 프로젝트 libertree-catalogue)
포트127.0.0.1:${LIBERTREE_HOST_PORT:-3101} → 3001
주입 환경LIBERTREE_APP_MODE=read-only, LIBERTREE_DB_PATH, LIBERTREE_BLOB_ROOT, ADMIN_USER/ADMIN_PASSWORD
마운트데이터·블랍 모두 read_only 바인드 (/data/repository/libertree-app/data, /data/repository/libertree)
보안read_only: true, cap_drop: ALL, no-new-privileges, pids_limit: 128, tmpfs /tmp
/api/health는 보호된 준비성 프로브다. 오설정/카탈로그 접근 불가 시 503, 자격증명 누락/오류 시 401, 정상 시 200. 노출 라우트는 /, /search, /search/:id, /api/blob/:seq_id/:ext, /api/health 뿐이다.

7. 저장소·데이터 위치

경로내용
libertree-app/data/libertree.db정본 카탈로그 SQLite DB. PRAGMA journal_mode=WAL (WAL/SHM 사이드카 동반). 크롤러 db_libertree.py 기본 경로이며 papers.db와 독립
data/libertree.db구(舊)/대체 경로. 데이터 경로 계약은 저장소 루트 기준 data/libertree.db와 libertree-app/data/libertree.db를 함께 인지
libertree/AAAA/BBBB/…PDF·텍스트 블랍 저장소. 12자리 zero-padded seq_id를 2단계 폴더로 분산. 예: libertree/0000/1234/000123456789.txt (leaf당 최대 10,000개, 최대 1조 개)
.cache/크롤러·Auto-Add 로그
crawler/.envAPI 키·사이트별 공개 검색 키 (gitignore)
data/papers.db는 구 크롤러(finolaw 대시보드/검색)의 DB로 카탈로그(libertree.db)와는 별개다. 열람앱 데이터 경로 계약은 papers.db를 앱 데이터로 사용하는 것을 거부한다.
libertree/ 블랍 트리는 대용량(약 1.6TB 규모)으로, 웹앱(열람앱)에는 항상 읽기 전용으로 마운트된다. 데이터 백업은 data/·libertree/ 디렉터리를 tar/rsync로 처리한다.
