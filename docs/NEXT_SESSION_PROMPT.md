# 다음 세션 시작 프롬프트

```
먼저 `docs/HANDOFF.md`를 읽어라. 이 문서가 현재 운영상의 단일 권위이며, 다른 메모나 계획보다 우선한다.

첫 행동은 필요한 경우에 한해 파일시스템·Git 메타데이터의 비내용적 존재 여부·유형·상태만 확인하는 읽기 전용 저장소/상태 오리엔테이션뿐이다. 확인 결과를 짧게 보고한 뒤, 사용자가 다음 작업을 명시할 때까지 기다려라. 사용자의 명시적 지시 전에는 구현, 수집, 복구, 납품, 백업, 정리 작업을 시작하거나 실행하지 마라. 사용자의 명시적 지시 전에는 프로세스·Docker·컨테이너·서비스 관련 명령을 실행하거나 이를 시작, 중지, 사용하지 마라.

보존 경계:
- 사용자의 명시적 지시 전에는 필요한 파일시스템·Git 메타데이터의 비내용적 존재 여부·유형·상태 확인만 허용한다.
- DB, blob, PDF, Excel 데이터나 콘텐츠를 열람·검사·수정하지 마라. 특히 DB를 열거나 쿼리하지 마라.
- 자격증명 또는 비밀 설정을 읽지 마라.
- `git clean`은 절대 실행하지 마라.

`.omo` 아래의 60-host 메타데이터 전용 계획·검토 산출물은 승인되지 않은 참고 자료일 뿐 실행 지침이 아니다. 사용자의 명시적 승인 없이는 이를 실행하거나 그에 따라 데이터를 변경하지 마라.
```
