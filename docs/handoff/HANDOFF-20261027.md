### 꼭 지킬 규칙
- temis(`temis-*` 컨테이너·DB·폴더·tmux)는 조회·접속·수정 모두 금지.
- 사이트 요청은 Fetcher 만(robots 먼저, 정직한 UA `LibertreeCollector`, 같은 호스트 1.5초 이상, 동시 금지). 403/429/챌린지·로그인은 즉시 멈추고 우회하지 않는다. IP 를 바꿔 다시 치지 않는다.
- 실패 감시: 한 실행에서 최근 20건이 종류와 상관없이 전부 실패면 자동 취소(서버 `~/streak-watch-20261027/watch.py`). kmcc 에서 502·연결 오류 혼합으로 감시가 안 걸려 실패 요청 약 2,500건이 나간 일이 있어 이렇게 바꿨다.
- 운영 DB 쓰기·배포·새 대형 수집·보안 설정은 사용자 승인 뒤. 반영은 새 행만(기존 행 수정·삭제 없음), 충돌은 보류.
- 비밀값(.env, 토큰, 키)은 읽지도 적지도 않는다. 사용자 계정 이메일은 외부로 보내지 않는다.
- 서버 보안·방화벽 설정은 관리자 몫 — 바꾸지 않는다.
