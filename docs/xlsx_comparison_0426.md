# `input.xlsx` vs DB 비교 리포트 (2026-04-26)

## 개요

사용자가 수동 정리한 마스터 리스트(`input.xlsx`, 20,352행 / 17,171 unique)를 DB의 `metadata.documentNumber`와 정규화 후 정확 비교.

> 정규화 규칙: 양쪽 모두 trailing `-` 및 `.md` 확장자 제거 후 문자열 일치.

## 결과 요약

| 지표 | 값 |
|---|---:|
| xlsx 총 행수 | 20,352 |
| xlsx unique (정규화 후) | 17,171 |
| DB unique documentNumber | 244,866 |
| **xlsx → DB 정확 매칭** | **17,162 (99.95%)** |
| 미매칭 | **9** |

### 매칭된 17,162건의 사이트 분포

| site_id | 매칭 occurrence |
|---|---:|
| nts-taxlaw-qt | 22,754 |
| nts-taxlaw-pd | 6,765 |
| nts-taxlaw (legacy site_id) | 7 |

> 한 documentNumber가 여러 doc_id로 중복 저장된 케이스가 있어 occurrence 합계가 unique 매칭(17,162)보다 큼. 별도 데이터 품질 이슈로 추후 dedup 검토 가능.

## 미매칭 9건 분류

### A. 입력 오타 추정 (2건) — 조치 불필요
| raw | 추정 정정 |
|---|---|
| `대정지방법원-2006-가단-1803.md` | `대전지방법원-2006-가단-1803` |
| `울중앙지방법원2024가단5198220.md` | `서울중앙지방법원-2024-가단-5198220` (구분자 누락 + 첫 글자 누락) |

→ xlsx 입력 시점의 오타. DB에 실제 사건이 있을 가능성 높음. 사용자 측 xlsx 정정 권고.

### B. 진짜 누락 후보 (7건) — 보충 검토 필요

| raw | 비고 |
|---|---|
| `대법원-2025-두-34754` | 2025년 최신 사건. crawl 이후 추가됐을 수도 |
| `법인세과-4278` | 사건번호 형식 일치, DB에 진짜 없음 |
| `서면인터넷방문상담5팀-501` | 동일 |
| `서울고등법원-2011-누-29290` | 2011년 사건, DB에 같은 패턴 다수 있는데 이 건만 없음 |
| `서울고등법원-2011-누-42187` | 동일 |
| `서울고등법원-2013-누-14056` | 동일 |
| `서울고등법원-2024-누-71253.md` | 2024년 사건 |

→ DB의 `LIKE '%키워드%'` 부분 검색에서도 매칭되지 않아 **실제 누락**으로 추정. 단 수가 매우 적어(전체의 0.04%) 영향 미미.

## 결론

- **사용자 ground-truth 대비 99.95% 일치**. 우리 DB가 xlsx 마스터 리스트의 거의 전수를 보유.
- 미매칭 9건 중 **실질 누락은 최대 7건** (2건은 xlsx 측 오타).
- xlsx의 22건 `헌법재판소` 사건도 DB에 정상 보유 확인 (DB 전체 헌법재판소 사건 353건 보유).
